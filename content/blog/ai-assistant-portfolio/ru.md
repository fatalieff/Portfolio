Я хотел добавить в портфолио AI-ассистента, который отвечает на вопросы посетителей. Цель была простой: пользователь, спрашивающий о React, Next.js или контактах, должен получать корректный ответ за несколько секунд.

## Выбор: Groq + Llama

Я выбрал Groq — это быстро, предоставляет простой OpenAI-совместимый endpoint, а модель `llama-3.3-70b-versatile` даёт качественные ответы. Никакого SDK не нужно — достаточно обычного `fetch` POST.

## Промпты для каждого языка

Ключевая деталь — сборка системного промпта для каждого языка. Сайт работает на трёх языках, поэтому я беру контекст из словаря каждого языка: имя, роль, локация, текст «обо мне», навыки, проекты, почта и соцсети. В начале промпта задаётся правило языка:

```
Cavabları həmişə Azərbaycan dilində yaz.
```

Так модель никогда не ответит не на том языке.

## Стратегия fallback

Сайт должен работать, даже если AI-сервис недоступен. Поэтому запрос сначала идёт в API, а при ошибке включаются локальные заготовленные ответы — посетитель получает ответ, не замечая разницы.

## Итог

Несколько часов работы сделали сайт заметно живее. Главный урок: добавляя AI-функции, всегда продумывай «оффлайн» путь — ошибки API не должны ломать пользовательский опыт.
